1. Product Rule in Implicit Diff
$$\frac{d}{dx}[xy] = x\frac{dy}{dx} + y \quad \text{and} \quad \frac{d}{dx}[u(x)v(y)] = u\cdot v'(y)\frac{dy}{dx} + u'(x)\cdot v$$

Watch negative signs in front of products like $-4xy$: wrap the entire product rule in parentheses!

2. Chain Rule in Implicit Diff
$$\frac{d}{dx}[f(y)] = f'(y)\cdot\frac{dy}{dx} \quad \text{and} \quad \frac{d}{dx}[\sin(xy)] = \cos(xy)\cdot\left(y + x\frac{dy}{dx}\right)$$

Whenever you differentiate a term containing $y$ with respect to $x$, multiply by $\dfrac{dy}{dx}$ ($y'$).

3. Horizontal Tangent Lines
$$\text{Numerator of } \frac{dy}{dx} = 0 \quad (\text{and Denominator } \neq 0)$$

Substitute the relationship back into the original curve equation to verify real points exist.

4. Vertical Tangent Lines
$$\text{Denominator of } \frac{dy}{dx} = 0 \quad (\text{and Numerator } \neq 0)$$

If both numerator and denominator equal $0$ at a point, further analysis is needed!

5. Second Derivative $\left(\dfrac{d^2y}{dx^2}\right)$ Pro-Tip for Point Evaluations

Differentiate the implicit equation a second time (or use the Quotient Rule on $\dfrac{dy}{dx}$) and plug in your known $\left(x, y, \dfrac{dy}{dx}\right)$ values immediately before doing heavy algebra! Also recall: $\dfrac{d^2y}{dx^2} < 0 \Rightarrow$ Concave Down (tangent line is an overestimate); $\dfrac{d^2y}{dx^2} > 0 \Rightarrow$ Concave Up (tangent line is an underestimate).
